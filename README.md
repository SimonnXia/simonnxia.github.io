# Simon Xia — Design Engineering Portfolio

Personal portfolio of Simon Xia, a Design Engineering undergraduate at Imperial College London.

**Live website:** https://simonnxia.github.io/

## Selected work

- AxisPro — motorised miniature-painting workstation
- Jìng — The Path — campus-space design and co-design study
- STREAM X — vehicle surface modelling and aerodynamic analysis
- SIMREST Q2 — bedside product concept and interface study
- MODUFRAME — sustainable aircraft-seat concept

The site includes a scroll-driven Three.js introduction, project narratives, an interactive portfolio book, a software capability wheel, and downloadable portfolio/CV PDFs.

## Preview and check

The website is static and its browser dependencies are bundled locally. No install or build is required.

```sh
npm start
# Open http://127.0.0.1:4173
npm run check
npm run check:book
```

## Publish updates

GitHub Pages serves the root of the `main` branch. Changes pushed to `main` publish automatically. `.nojekyll` keeps the site as plain static files.

Edit the root HTML/CSS/JavaScript files. Project copy is in `content.js` and `project-process.js`; public assets and downloadable PDFs are in `assets/`.
